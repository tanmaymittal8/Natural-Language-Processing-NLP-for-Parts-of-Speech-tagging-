# Natural-Language-Processing-NLP-for-Parts-of-Speech-tagging

●	Bulit a Hidden Markov Model to perform part of speech tagging on input sentences 
●	Developed a Vertibi algorithm to determine the grammar of a given word in a test data set to understand the context of the input sentence 
●	Achieved 90% accuracy on the Brown Development dataset in determining whether a word in a sentence is a noun, verb, adjective, adverb, etc along with determining part of speech for ambiguous words which can be multiple parts of speech
